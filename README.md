# 🐝 Iman's Pakistan Bumblebee Quiz

A Streamlit quiz app featuring difficult Pakistan-history MCQs with a space-themed animated interface.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud

Use these settings:

- Repository: `iman-coll/Bumblebee-Iman`
- Branch: `main`
- Main file path: `app.py`

The root `app.py` launches the quiz stored in `Bumblebee_quiz_app/app.py` and replaces the old remote Picsum animation image with an embedded SVG. The app therefore does not depend on an external image host for its animation.
